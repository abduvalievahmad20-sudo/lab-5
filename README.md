# Teplica.log — IoT Smart Greenhouse
Статический проект (HTML/CSS/JS). Распакуйте архив и откройте `index.html`.
`simulator.js` — модель датчиков, `automation.js` — правила и инциденты, `storage.js` — localStorage, `dashboard.js` — сводка, участки, датчики, пульт, допуски; `alerts.js`, `analytics.js` — инциденты и графики.
